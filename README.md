## Deskripsi

Todo App merupakan aplikasi sederhana untuk menampilkan dan 
mengatur daftar tugas secara visual. Aplikasi ini menampilkan daftar Todo,
detail dari Todo yang dipilih, serta form untuk membuat Todo baru.

Tampilan Todo App menggunakan layout dua panel dengan CSS Grid dan
dirancang agar responsif pada perangkat desktop maupun mobile.
