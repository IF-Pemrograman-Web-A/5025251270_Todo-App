## Deskripsi

Todo App adalah aplikasi sederhana untuk membantu pengguna mengelola daftar tugas. Pengguna dapat membuat, 
melihat, mengedit, menghapus, dan menandai tugas sebagai selesai, serta melihat detail tugas seperti 
deskripsi, prioritas, tanggal jatuh tempo, dan status.
